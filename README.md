# validarips

Módulo RIPS — **Resolución 948 (JSON)** y **Resolución 3374 (TXT/ZIP)**.

## Descargar (importante)

**Release oficial (recomendado):** [v1.2.8](https://github.com/jcmencop2021/validarips/releases/tag/v1.2.8)

| Archivo | Uso |
|---------|-----|
| `MODULORIPS_v1.2.8_Windows_completo.zip` | Exe + fuente + leeme |
| `ModuloRIPS948.exe` | Solo programa Windows |
| `MODULO_RIPS_948_v1.2.8.zip` | Solo carpeta `MODULO_RIPS_948` (Python) |

El programa está en la carpeta **`MODULO_RIPS_948`**. Pasos y alternativas: **[COMO_DESCARGAR.txt](COMO_DESCARGAR.txt)**

## Ejecutar

```bat
cd MODULO_RIPS_948
python -m pip install -r requirements.txt
python app.py
```
